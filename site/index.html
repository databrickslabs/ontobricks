OntoBricks

Knowledge Graph Builder for Databricks

Transform Unity Catalog tables into a materialized knowledge graph. Design ontologies (OWL), map with R2RML, materialize into Delta and Lakebase, reason with OWL 2 RL / SWRL / SHACL, and query through GraphQL — with LLM-assisted automation along the way.

From tables to graph in four clicks

1. ImportPull UC metadata into a domain.
2. DesignModel entities, relations, and rules.
3. MapBind ontology properties to table columns.
4. MaterializeBuild the graph and start querying.

OntoBricks is a Databricks Labs project provided AS-IS for exploration.
