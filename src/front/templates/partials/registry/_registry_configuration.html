SQLite Registry REGISTRY_BACKEND=sqlite
  • The database file lives on the app's local disk (REGISTRY_SQLITE_PATH, default in the temp directory).
  • It is restored at startup from, and snapshotted after writes to, /Volumes/<catalog>/<schema>/<volume>/_registry/<schema>.sqlite on the registry Volume (override: REGISTRY_SQLITE_SNAPSHOT_PATH).
  • New domains default to the Lakehouse graph backend: this app has no Lakebase graph.
Run a single app instance. A crash can lose the last few seconds of writes (the window between a write and its snapshot). Use Check Access to see the file and snapshot paths and test the snapshot.
