Unity Catalog schema — triples views & registry tables
This UC schema hosts the Delta Lake views that expose Knowledge Graph triples to SQL queries (e.g. triples, entities, relationships) and the Lakebase-backed registry tables that store contexts, versions, permissions, and global configuration. The app service principal needs USE CATALOG, USE SCHEMA, and SELECT (plus CREATE TABLE / MODIFY for the registry).
Set up the registry

Choose the Unity Catalog schema for the registry. OntoBricks creates it if needed and gives the app's service principal access to it and to this app, using your permissions. You need USE CATALOG and CREATE SCHEMA on the catalog, or must own it.

      Troubleshooting
      • "You lack a privilege": you need USE CATALOG and CREATE SCHEMA on the catalog. Ask its owner to run GRANT USE CATALOG, CREATE SCHEMA ON CATALOG `<catalog>` TO `<you>`, or pick a catalog you own.
      • The schema already exists: granting on it needs you to own it or have MANAGE. Pick a new schema name if someone else owns it.
      • Can't read this app's permissions: the app needs the apps user scope and you need Can Manage on the app. Without them, add the app's service principal (on the app's Overview page) under Apps → Permissions → Can Manage by hand.
      • Can't run SQL on the warehouse: you need Can use on the SQL warehouse bound to the app. A stopped warehouse starts on the first check, which can take a few minutes.
      • Lakebase errors (service principal checks): the app needs its postgres resource bound to a Lakebase database with Can connect and create. Edit the app's resources, then redeploy.
      • Other users get "access denied": they need Can use on the app, and the app's service principal needs Can Manage on it (setup grants this).
      • Still stuck? Copy diagnostics and share the JSON with whoever supports this install. It contains check results only, never tokens.
