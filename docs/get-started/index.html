Get started

Run OntoBricks locally against your Databricks workspace.

Prerequisites

  • Python 3.10+
  • Databricks workspace with Databricks Apps enabled
  • SQL Warehouse in the workspace
  • Databricks Lakebase Autoscaling project, branch, and Postgres database
  • Unity Catalog Volume for binary artefacts and Delta triplestore views
  • uv package manager
  • psql (libpq client) on PATH for Lakebase permission bootstrap

Quick start

git clone https://github.com/databrickslabs/ontobricks.git
cd ontobricks
uv sync --extra lakebase
cp .env.example .env
scripts/start.sh

Edit .env with your Databricks host, token, warehouse ID, and Lakebase settings before starting. Full configuration steps are in the getting started guide on GitHub (master branch; develop may differ until merged).
