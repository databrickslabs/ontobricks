Features

Everything needed to go from Lakehouse tables to a queryable knowledge graph.

Ontology design

Visual OWL modeling for entities, attributes, and relationships.

R2RML mapping

Bind ontology properties to Unity Catalog tables and columns.

Delta + Lakebase graph

Materialize triples into a Delta-backed store and Lakebase Postgres graph engine.

Reasoning

Apply OWL 2 RL, SWRL rules, and SHACL data-quality shapes.

Query

Explore the graph visually and via an auto-generated GraphQL API.

OntoBricks is a Databricks Labs project provided AS-IS for exploration.
